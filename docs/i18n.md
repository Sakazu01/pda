# Interface languages

PDA's interface speaks **English** and **Bahasa Indonesia**.

- **Default:** the browser's language. An Indonesian browser gets Indonesian; everything else gets English.
- **Switch:** ⋯ menu → *Language: English* / *Bahasa: Indonesia*, or `Ctrl+K` → "language". PDA saves the open project, remembers the choice in this browser (`rancang:lang`) and reloads.
- **Scope:** the interface changes language: menus, panels, hints, messages, the PRD template and the headings PDA writes into the PRD. **Diagram content does not**: what you typed, the built-in example diagrams and the sample text inside frameworks stay as written.

## How it works

The source has text in both languages, because older modules were written in English and newer ones in Indonesian. Two dictionaries translate the page as it renders. A `MutationObserver` covers text nodes, `title`, `aria-label` and `placeholder`, and never touches the canvas or inputs:

| File | Role |
|---|---|
| `src/i18n/lang.ts` | `LANG`, `setLang()`, the menu entries, and `L(en, id)` for text built in code |
| `src/i18n/id.ts` | English → Indonesian (`I18N` exact strings, `I18N_RE` patterns) |
| `src/i18n/en.ts` | Indonesian → English (`EN` exact strings, `EN_RE` patterns). Long entries also match inside composed text |

## Adding or changing text

- New text built in code: `L('Saved to the folder.', 'Tersimpan di folder.')`.
- Fixed English text in `src/shell/body.html` or code: add its Indonesian to `I18N`.
- Fixed Indonesian text: add its English to `EN`.

`tests/lang.cjs` walks every page, panel and dialog in English and fails if any Indonesian text is left. `tests/lang-crawl.cjs` prints what is left, for fixing.
